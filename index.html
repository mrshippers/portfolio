I'm a chartered physio who co-owns a clinic in West Hampstead and got tired of waiting for someone else to fix clinic software. So I built it. StrydeOS answers the clinic phone, books the slot, scores every patient for drop-off risk and cites its clinical answers from code, not from the model. Live in two clinics, built end to end in Next.js and TypeScript. Everything else on this page comes from the same habit: find the corner nobody is building for, then ship something I'd want to be judged on.

The orb is drawn from these five. Point at one.

01experience

StrydeOS founder

Feb 2026 to now, London

An operating system for UK MSK clinics that sits on top of the practice-management system they already run. I own all of it: engineering, product, infrastructure, security and the GDPR paperwork.

  • Ava answers the clinic phone. Twilio into ElevenLabs conversational AI running Claude, with tool calls into a TypeScript booking layer that writes to Cliniko and WriteUpp.
  • Pulse sorts patients into lifecycle cohorts, scores drop-off risk and runs re-engagement on whatever channel each patient actually replies to. Measured against a randomised holdout, so the number it reports is a real one.
  • Evidence gives cited clinical answers from local open-weight models, including a Gemma I distilled and fine-tuned myself. Citations are built in code, never written by the model.
  • The release gate. 505 simulated callers run before anything ships. Under 95%, or a single P0, and it doesn't.
  • The frontend is Next.js, React and TypeScript on a typed token layer, so every surface retints from one palette. Contrast audited in both themes.
