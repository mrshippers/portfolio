a fixer that can only fix one thing.

the reflex is a job that reads the receptionist's fault ledger, writes a one-sentence prompt fix, merges it and deploys it with nobody watching. what makes that safe is how little it is allowed to do. a fault becomes a candidate at a count of two, or one if it was rated high. the drafter is a fixed table with one row, a repeated question about which part of the body hurts, so that is the only fault it can ever merge. everything else gets a pull request carrying the evidence and waits for a person. before merging, the classifier runs again on the live diff: four files allowed, no protected word in the signature or the changed text. then the war room has to pass the drafted sentence, on the pull request's own head, three calls out of three. any missing result, a dead transport or a red check means no merge. the merge pins the exact head the war room passed. the second fix of the afternoon is the lesson. the first version deployed a checkout of the merge commit. on a retry after main had moved, that would have rolled newer functions back. it now checks the merge is an ancestor of main, then deploys main's tip. the cost is stated nowhere: the war room tested the live prompt plus one sentence, and the deploy ships whatever else main holds.
